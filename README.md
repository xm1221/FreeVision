# FreeVision · 自由视界

**在原版的三种人称视角之外，给你一枚完全自定义的镜头。**

按住一个键，用鼠标和 WASD 把相机摆到你想要的位置；松开即预览，短按保存；此后短按同一个键，
随时在「原版视角」和「你的视角」之间切换。

- **平台**：Fabric + Forge 双端（Architectury 构建，两端共用同一份 `common` 代码）
- **版本**：Minecraft `1.20.1` / Java `17`
- **侧别**：纯客户端。服务端不需要装，也不发任何网络包，不改动 gameplay 数据

---

## 为什么它不是自由相机

自由相机（freecam）会**脱离**玩家：镜头在世界上有一个自己的坐标，玩家被留在原地，两者之间没有任何约束。

FreeVision 的镜头永远是**挂在玩家身上的一套机位**：

| | 自由相机 | FreeVision |
|---|---|---|
| 镜头位置 | 世界坐标，玩家走远了镜头不动 | 相对玩家的眼睛，玩家走、跑、跳、游泳、骑马都跟着 |
| 镜头朝向 | 自己独立，玩家转头无关 | 玩家视角朝向 + 偏移量，转头时镜头跟着绕玩家转 |
| 交互 | 常常和准星脱节，或干脆禁用 | 准星仍在相机射线上，且被限制在玩家自身可达范围内 |
| 存续 | 松手即结束 | 存下来，成为一个可反复启停的「视角」 |

保存下来的东西是 **六个数字**（偏航偏移、俯仰偏移、翻滚、距离、高度、侧移）。
它描述的不是「相机在哪里」，而是「相机如何相对玩家摆放」——这正是它能够跟着你走的原因。

## 操作

全部键位都在 `选项 → 控制 → 自由视界` 里可改。

| 键位 | 默认 | 作用 |
|---|---|---|
| 自定义视角 | `F8` | **短按**：切换已保存视角 / 保存草稿；**按住**：开始调整机位 |
| 切换视角槽位 | `F9` | 在多个已保存视角之间轮换 |
| 调整时：向左/向右翻滚 | `,` / `.` | 荷兰角（用于构图） |
| 调整时：机位归位 | `R` | 相机回到双眼位置，重新开始摆 |
| 移动 | `WASD` | 沿相机自身的朝向平移机位 |
| 升降 | `空格` / `Shift` | 竖直方向升降 |
| 精调 | `Ctrl` | 移动速度降到 1/5 |
| 推拉 | 鼠标滚轮 | 沿视线轴前后推拉 |

### 完整流程

1. **按住 `F8`** —— 进入调整。此时玩家被定住，鼠标和 WASD 交给你手中的相机。
2. **摆放机位** —— 鼠标转镜头，WASD 挪位置，滚轮推拉，HUD 实时显示六个数值。
3. **松开 `F8`** —— 相机停在原地作预览，HUD 提示「视角已就绪」。
4. **短按 `F8`** —— 保存，相机平滑退回原版视角（`Esc` 放弃本次调整，按住可以继续改）。
5. **再短按 `F8`** —— 进入刚保存的视角；此后每次短按都在它与原版视角之间切换。

想省掉第 5 步，把配置里的 `enterOnSave` 改成 `true`：保存后直接留在该视角里。

首次使用没有存档时，短按会提示你按住键位开始调整。

## 状态机

| 当前状态 | 输入 | 结果 |
|---|---|---|
| `VANILLA` | 按住 | → `SCULPTING`（从当前画面接管，不跳变） |
| `VANILLA` | 短按（已有存档） | → `ACTIVE`，飞入保存的视角 |
| `VANILLA` | 短按（没有存档） | 提示「按住键位开始调整」 |
| `SCULPTING` | 鼠标 / WASD / 滚轮 / `,` `.` | 编辑六个机位数值 |
| `SCULPTING` | 松开 | → `DRAFT`，相机停在原地作预览 |
| `SCULPTING` / `DRAFT` | `Esc` | 放弃本次调整，平滑退回原版视角 |
| `DRAFT` | 短按 | 保存 → 平滑退回原版视角（`enterOnSave=true` 时直接留在该视角） |
| `DRAFT` | 按住 | → `SCULPTING`，接着改 |
| `ACTIVE` | 短按 | → `LEAVING`（220ms 平滑过渡）→ `VANILLA` |
| `ACTIVE` | 按住 | → `SCULPTING`，在当前视角上继续微调 |
| 任意编辑态 | 打开界面 | 会话停在 `DRAFT`，已摆好的机位不丢失 |

- `SCULPTING` / `DRAFT` 期间玩家被冻结输入，原版游戏键位（丢弃、攻击、打开背包……）全部静音，
  松开按键后不会有积压的点击突然触发。
- 「进/出」都用同一条 220ms 的缓动动画，起点取自觉性相机当前的真实位置——所以即使你正处在
  原版第三人称、床上或旁观者视角，接管的一瞬间画面也不会跳。

## 配置文件

`config/freevision.json`，自动生成，随时可手改：

```json
{
  "settings": {
    "holdThresholdMs": 220,
    "sculptSpeed": 0.22,
    "maxOffset": 16.0,
    "transitionMs": 220,
    "smoothTransitions": true,
    "enterOnSave": false,
    "avoidClipping": true,
    "cameraPicking": true,
    "disableViewBobbing": true,
    "showHud": true,
    "playSounds": true,
    "precisionModifier": true,
    "maxSlots": 3
  },
  "presets": [
    { "yawOffset": 0.0, "pitchOffset": -18.0, "roll": 0.0, "distance": 4.5, "height": 1.6, "side": -0.8 }
  ],
  "activeSlot": 0
}
```

| 选项 | 说明 |
|---|---|
| `holdThresholdMs` | 短按与按住的分界，默认 220ms |
| `maxOffset` | 机位可以离眼睛多远（格），防止摆出离谱的机位 |
| `avoidClipping` | 启用视角时把相机从墙里拉出来（和原版第三人称一样），调整时关闭以便自由摆放 |
| `cameraPicking` | 让准星从相机射出，而不是从玩家眼睛射出 |
| `transitionMs` | 进出的平滑过渡时长，设为 0 即硬切 |
| `enterOnSave` | `true` = 保存后直接留在该视角；`false`（默认）= 保存后回原版，下次短按才进入 |

配置改完重进游戏生效；存档（`presets`）在保存时立即写盘。

## 安装

1. 装好 **Architectury API**（Fabric 端还需要 **Fabric API**）。
2. 把 `freevision-fabric-1.0.0.jar` 丢进 Fabric 的 `mods/`，或 `freevision-forge-1.0.0.jar` 丢进 Forge 的 `mods/`。
   （两个 jar 内容不同，别混装。）

Forge 端声明了 `displayTest = "IGNORE_ALL_VERSION"`，客户端装了、服务端没装也可以正常进服。

## 构建

```bash
# Gradle 本身需要 JDK 21+，产物字节码是 Java 17
export JAVA_HOME=/path/to/jdk-21
./gradlew build
# 产物：fabric/build/libs/freevision-fabric-1.0.0.jar
#       forge/build/libs/freevision-forge-1.0.0.jar
```

开发运行：`./gradlew :fabric:runClient` 或 `:forge:runClient`。

## 已知限制

- **与原版第三人称互不干扰但不叠加**：启用自定义视角时，镜头由 FreeVision 接管；此时按 `F5` 只会改变原版记录的人称状态，画面仍是你保存的机位（退出后立即生效）。
- **不会让服务端看到任何异常**：不发送额外的移动/交互包，机位完全在客户端。
- **交互距离**：可以从自定义机位瞄准，但命中点仍然被限制在玩家自身的手臂范围内，避免触发服务端的距离校验。机位离得越远，可交互范围越接近原版。
- **水下/熔岩雾效**按相机位置计算（这是正确行为，但穿墙镜头会看到墙后坐标的雾效浓度，属于原版机制）。
- 与其它也接管相机的模组（如自由相机）同时使用时，以本模组为准。
